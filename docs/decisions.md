# Decisions

| Date | Decision | Notes |
|---|---|---|
| 2026-10-02 | Full port of Highway Patrol II, reverse engineering the whole executable including the game engine. | The graphics and presentation are kept; the playability is reworked. |
| 2026-10-02 | Targets: desktop host and RP2350. | Assets in flash, no heap in the core. |
| 2026-10-02 | Reworked rather than preserved: handling and controls, game loop and pacing, difficulty and AI, frame rate and responsiveness. | The original behaviour is still documented (`vehicles.md`, `game.md`) as the reference for what exists. |
| 2026-10-02 | Reference binary: the Quartex NTSC crack (`assets/hp.adf`), the only build available. | Crack changes found so far: manual-lookup protection unreferenced, "QUARTEX 1990!" on the end screens. |
| 2026-10-02 | Language: C++23. | |
| 2026-10-02 | Display model: 8-bit pixels (palette indices) in a screen split into at most two viewports, each with a 256-colour palette; copper colour changes inside a viewport become separate palette entries. | Replaces a per-row palette design. |
| 2026-10-02 | Input is recorded as keystroke events (press and release); the engine keeps no key levels. | |
| 2026-10-02 | Python tools live in `scripts/` with the `hp2lib` package, run from the repo's `.venv` (`uv sync`). | |
| 2026-10-02 | Data inside `hp.prg`: tables that can be computed (sine, cosine, arctangent) are rewritten; any other data the port takes from the executable is vetted case by case. The host loader reads the executable unrelocated, by hunk and offset. | Read from the executable so far: the palette lists title (`1:28e0`), office (`0:ca94`), office dim (`0:ca6e`), score (`0:7766`), view (`0:a520`) and view red (`0:a734`); PRESENT.DIF's play list (`1:2870`, 27 `{frame, delay}` steps); the periods of the three bare sound effects (siren 864, shot 427, crash 640: their playback rates); the mission table (`1:23ae`: type, target speed and bounty of the six posters, written into `game_state.hpp` as constants). |
| 2026-10-02 | The opening presentation keeps the original's pacing, from cycle counts of its busy waits (`game.md`, "Opening presentation"); the disk waits become a fixed 2 s hold behind the logo. Space or Enter skip to the finished title. | Counted, not measured: no emulator run yet. |
| 2026-10-02 | The port is a rewrite, not an emulation: the original is the reference for what things do and mean, not for hardware quirks, artefacts or bugs. | Sound: no Paula or LED-filter modelling; semitone steps are equal-tempered floats, not the original's period table. |
| 2026-10-02 | Audio: four voices resampled with a 6-point, 5th-order B-spline, mixed at 48 kHz (two voices per side, no clipping) into a lock-free ring that the platform drains; the main loop steps the engine with the elapsed time. The music player runs on the same sample clock at the module's tempo, with PAL clocks as the module's reference. | A voice takes its volume at once when a note starts and ramps later changes. |
| 2026-10-02 | The port reads the game files straight from the disk image (`assets/hp2.adf`) with ADFlib. | The extracted directory stays for the Python tools. |
| 2026-10-02 | Every asset the game uses is decoded into `EngineAssets`: tables of views indexed by enums named by meaning (pictures, palettes, sprite banks, fonts, sounds) plus the title animation, the title music, the road map and the scenery, all as records with offsets and counts rather than nested spans. | The host fills it from the disk image; the firmware binds it to the flash image. |
| 2026-10-02 | Target: Adafruit Feather RP2350 (8 MB flash: 1 MB firmware, 7 MB assets). The decoded assets are packed by `scripts/pack_assets.py` into a flash image laid out as the engine's types, with a generated layout header and a SHA-256 the firmware checks at boot. | `FlashAssets` takes the image's base address, so the host test reads `assets.bin` through the same function the firmware uses. |
| 2026-10-02 | The office, station and end screens keep the original's pictures, layout and rules; the controls are keyboard events (arrows move the office pointer, Up and Down the station cursor, Space or Enter act), the waits are shorter (half-second lights, 1/16 s fade steps), and the crack's "QUARTEX 1990!" line is left out. | `game.md`, "The port's screens between missions". |
